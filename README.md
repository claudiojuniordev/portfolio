
# Portfólio Pessoal - Claudio Junior

Este é o repositório do meu portfólio pessoal como **Software Developer**, com foco em **Python, Cloud, AI e Power Platform**. O conteúdo profissional (experiência, formação, certificações e stack técnica) é extraído diretamente do meu currículo. É um site estático, rápido, acessível e responsivo, com visual moderno inspirado em portfolios de desenvolvedores, formulário de contato integrado ao WhatsApp e download/visualização do currículo em PDF.

## 🧠 Tecnologias Utilizadas

- **HTML5** semântico (landmarks, `aria-label`/`aria-labelledby`)
- **CSS3** puro — design tokens, `clamp()` para tipografia fluida, grid/flexbox, `@media` para responsividade e `prefers-reduced-motion`
- **JavaScript** vanilla — menu mobile, scroll-spy via `IntersectionObserver`, efeito typewriter e fundo de partículas em `<canvas>`
- Integração com **API do WhatsApp**
- Sem build step e sem dependências externas — publicável direto no GitHub Pages

## 📁 Estrutura do Projeto

```

```

## 🧩 Funcionalidades

- Navegação fixa com menu hambúrguer no mobile e destaque automático da seção atual (scroll-spy).
- Hero com efeito de "digitação" alternando os papéis do currículo (Software Developer, Python, Cloud, AI, Power Platform).
- Seções de **Sobre**, **Skills** (agrupadas por categoria), **Projetos** (pronta para receber repositórios reais), **Experiência**, **Formação & Certificações** e **Currículo** (download + visualização embutida do PDF).
- Formulário de contato integrado ao **WhatsApp**, além de links diretos de e-mail, LinkedIn, GitHub e telefone.
- Totalmente responsivo, com animações que respeitam `prefers-reduced-motion`.

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/claudiojuniordev/portfolio.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd portfolio
   ```

3. Abra o arquivo `index.html` em qualquer navegador moderno.
